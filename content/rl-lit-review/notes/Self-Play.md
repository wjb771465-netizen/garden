# 自博弈笔记：从朴素自博弈到 PSRO

自博弈（self-play）通过与当前或历史版本的自己、以及共同演化的其他策略对抗，持续生成训练数据。这里主要讨论对抗博弈：**对手从哪里来、按什么分布采样，以及怎样避免策略循环**。[1]

本文按“朴素自博弈 → FSP → PFSP → PSRO”展开。这是理解方法差异的一条主线；PSRO 是更一般的框架，FSP 等方法也可以放进它的框架中理解，并非四个互斥的算法类别。[1, 2]

## 1. 朴素自博弈：只与最新版本对决

每轮将当前策略复制为对手，训练出能够击败它的新策略，再更新对手。对手可以在一段训练内冻结，但始终只保留最新版本。

优点是简单，对手难度随学习进度自然提升；缺点是容易只学会针对眼前对手的反制，并遗忘此前的能力。

典型问题是**非传递性**：A 胜 B、B 胜 C，但 C 又胜 A。例如石头剪刀布中，只对最新版本做最佳响应，可能不断沿“石头 → 布 → 剪刀 → 石头”循环。击败上一版不能证明整体实力持续提高，更不能证明趋近纳什均衡。[1, §3.2.2]

## 2. FSP：与历史策略的平均混合对抗

虚拟自博弈（Fictitious Self-Play, FSP）继承虚拟博弈（Fictitious Play, FP）的思路：针对对手历史行为的经验平均策略学习最佳响应，而不是只针对最新策略。[1, §3.2.3]

### 2.1 简单实现：历史池均匀采样

保存历史策略快照 $\Pi_t=\{\pi_1,\ldots,\pi_t\}$，每局开始均匀抽取一个对手：

$$
j\sim\operatorname{Uniform}\{1,\ldots,t\},\qquad
\bar\pi_t=\frac{1}{t}\sum_{j=1}^{t}\pi_j.
$$

这里的混合表示**整局开始时选择一份策略**，不是把多个神经网络的参数取平均。新策略学习应对整个历史混合，因此旧的反制策略仍有机会出现，能缓解遗忘与循环。

这个实现适合把握核心直觉，但“保存快照并均匀抽样”不等于完整复现原始 FSP/NFSP；历史平均的权重也取决于策略生成与记忆方式。[1, 3]

**代价与边界**：池子扩大后，大量容易击败的旧策略可能占用训练预算；有限快照、近似最佳响应也会影响效果。经典两人零和 FP 的均衡结论关注经验平均策略，不能直接解释为“最新网络一定收敛”。[1, 3]

### 2.2 δ-uniform：只在最近一段历史里均匀采样

**δ-uniform** 使用 $\delta$（delta）控制历史范围：按训练时间截断历史，只在最近的一段策略中均匀采样。[1, §3.2.4；4, §V]

- $\delta=0$：保留全部历史，得到全历史均匀采样。
- $0<\delta<1$：丢弃较早策略，在最近约 $1-\delta$ 比例的历史中均匀采样。
- $\delta=1$：只选最新策略，退化为朴素自博弈。

它在历史覆盖与训练效率之间折中：近期对手通常更有挑战，但丢掉过早策略，也可能丢掉仍有价值的反制。**训练时间在这里决定候选范围，范围内仍然是均匀采样。**

根据 _A Comparison of Self-Play Algorithms Under a Generalized Framework_ 的策略演化实验，截断历史的 $\delta=0.5$-uniform 仍有循环与遗忘问题：策略容易被刚移出采样窗口的旧版本击败，在持续应对历史策略方面不如全历史均匀采样（$\delta=0$）。[4, §VIII.C]

### 2.3 NFSP：用网络学习平均策略

神经虚拟自博弈（Neural Fictitious Self-Play, NFSP）用两个网络实现“最佳响应 + 历史平均”，不必保存并轮流加载所有历史策略：[3, §3]

- **最佳响应网络**：用强化学习训练 Q 网络，得到近似最佳响应策略 $\beta$。
- **平均策略网络**：用监督学习模仿自身过去采用最佳响应时的行为，得到平均策略 $\pi$。对应的行为样本用蓄水池采样（reservoir sampling）保存，避免有限缓冲区只记住近期数据。

每局以较小概率 $\eta$ 采用 $\beta$，其余采用 $\pi$：前者生成新的最佳响应行为，后者让对局主要围绕历史平均策略展开。训练后主要评估的是平均策略网络，而非最新的最佳响应网络。论文在 Leduc poker 中观察到 NFSP 接近纳什均衡。[3]

## 3. PFSP：按训练价值优先采样

优先虚拟自博弈（Prioritized Fictitious Self-Play, PFSP）同样维护策略池，但按当前策略与池中对手的对局表现分配采样概率。[1, §3.2.5]

设 $w_j$ 为**当前策略战胜对手 $j$ 的胜率**，优先函数为 $f$，则

$$
p(j)=\frac{f(w_j)}{\sum_k f(w_k)}.
$$

常见选择：

| 优先函数             | 更常采样的对手         | 训练意图                                   |
| -------------------- | ---------------------- | ------------------------------------------ |
| $f(w)=(1-w)^p,\ p>0$ | 当前策略较难击败的对手 | 暴露并修补弱点；$p$ 越大，偏向难对手越明显 |
| $f(w)=w(1-w)$        | 胜率接近 50% 的对手    | 集中在势均力敌的对局，减少过易或过难样本   |

这里的“强”主要是**相对于当前策略的克制关系**，不是一个全局排名。非传递博弈中，单一 Elo 或训练时长无法完整表示这种关系。

工程上还可按训练时间、近期进步等信息筛选或加权，但应写明具体规则；不能把所有历史池采样都称为标准 PFSP。PFSP 的核心是按对局表现设置优先级，δ-uniform 的核心是按时间截断后均匀采样。[1, 4]

**优点**：把预算投向更有训练价值的对手，减少均匀采样的浪费。**局限**：需要维护胜率估计，结果受优先函数与统计噪声影响；改变采样分布本身不等于获得纳什均衡保证。

## 4. PSRO：在策略空间中求解受限博弈

策略空间响应预言机（Policy Space Response Oracles, **PSRO**）把对手分布的选择交给元策略求解器，再通过强化学习寻找新的响应策略。[2]

核心链路是：

> 受限博弈（策略之间的 payoff 表）→ 求解 meta-strategy → oracle 针对它学习新策略 → 加入策略集 → 更新 payoff 表 → 下一轮。

### 4.1 两层求解

设两方策略池为 $\Pi_1,\Pi_2$，通过模拟对局估计收益矩阵：

$$
M_{ij}=\mathbb E\!\left[u_1(\pi_i^1,\pi_j^2)\right].
$$

1. **外层：求元策略。** 在这个受限博弈上运行元策略求解器（Meta-Strategy Solver, MSS），得到池内策略的混合权重 $\sigma_1,\sigma_2$。两人零和场景可以求受限博弈的纳什均衡。
2. **内层：学最佳响应。** 用 RL 等响应预言机（oracle），针对对方的混合策略学习新策略。例如第一方求

   $$
   \pi_{\mathrm{new}}^1\approx
   \arg\max_{\pi}\;
   \mathbb E_{\pi_j^2\sim\sigma_2}
   \left[u_1(\pi,\pi_j^2)\right].
   $$

3. **扩池并评估。** 将新策略加入相应策略池，补充新旧策略的交叉对局收益，再求下一轮元策略。

MSS 决定“针对谁练”，oracle 决定“怎样练出响应策略”。**元策略是策略池上的概率分布，底层策略才是实际出动作的网络。** PSRO 也允许使用其他 MSS，不要求每个变体都求纳什均衡。[2, §2]

### 4.2 为什么能处理循环

朴素自博弈会追逐最新反制；PSRO 保存反制关系，并在策略池上寻找混合解。石头、布、剪刀都进入池后，受限博弈的均衡是三者各以 $1/3$ 概率出场。训练目标转向应对这种混合，避免只在三个纯策略间来回替换。[1, §3.3.2]

因此，其优势可以概括为：**有明确的博弈论基础，通过维护策略集合与求解混合策略来处理非传递循环。**

“理论完备、解决循环”需要加上条件：在有限两人零和博弈中，使用精确收益、精确最佳响应与受限博弈均衡求解的 Double Oracle 有完整博弈的均衡收敛保证。PSRO 用模拟估计收益、用 RL 近似响应后，这些理想条件通常不再精确成立；一般和、多人或其他 MSS 还需分别讨论，不能统一宣称保证收敛。[2, §2]

### 4.3 为什么实现复杂

- **交叉评估**：两方各有 $n$ 个策略时，完整收益表有 $n^2$ 个组合，每项还需多局估计；新增一份策略也要补评估。
- **反复训练响应**：每轮都要训练近似最佳响应，训练不足会漏掉可利用的弱点。
- **元求解与管理**：要协调策略快照、收益矩阵、混合权重与停止条件；池子扩大后，存储、仿真和求解成本都增加。

受限博弈内的均衡只说明池内策略无法获利偏离；是否仍能被池外策略利用，要靠响应搜索继续检验。[2]

## 5. 案例

### 5.1 AlphaGo：行为克隆初始化，再自博弈强化

这里指 2016 年的 AlphaGo：[5]

1. **行为克隆**：用人类棋谱监督训练策略网络，预测专家落子。
2. **自博弈强化学习**：以监督策略初始化 RL 策略，与历史版本池中随机选择的对手对局，用策略梯度提高胜率。原文明确说明，这样做是为减少对当前策略的过拟合。
3. **价值学习与搜索**：用自博弈数据训练价值网络，并在落子时结合策略、价值和快速 rollout 做 MCTS。

行为克隆解决初始能力与探索起点；历史池采样解决对手覆盖。它们是训练链路中的不同环节，不能把 AlphaGo 仅归为“行为克隆”。这也不同于后续不依赖人类棋谱的 AlphaGo Zero。

### 5.2 OpenAI Five（Dota 2）：最新自博弈 + 动态历史池

OpenAI Five 使用 PPO 训练；**80% 对局对最新版本，20% 对历史版本**。历史池用于缓解只对近期策略优化导致的策略坍塌与遗忘。[6, §3.2、附录 N]

历史对手不是均匀采样：每个对手有质量分数 $q_j$，按 softmax 概率采样。当前策略击败某个历史对手后，会下调该对手的分数；仍能击败当前策略的对手会保有较高权重。

因此，可以将它作为 **FSP 思路的工程扩展**，但准确写法是“最新版本自博弈与动态加权历史池混合”，而非“纯均匀 FSP”。原文也仅称其与 fictitious play 的思路相近，并说明最终使用最新策略，而不是平均策略。[6, §5、附录 N]

### 5.3 AlphaStar：PFSP 与联赛训练

AlphaStar 将人类经验、强化学习与联赛训练结合起来。理解它的关键是区分两件事：**怎样产生有价值的新策略，以及怎样为已有策略安排对手。**[7, 8]

#### 人类经验提供起点与探索方向

先用人类回放监督训练策略，预测玩家动作，再以此初始化联赛中的智能体。强化学习期间，人类经验继续参与：用开局、建造顺序等统计量 $z$ 引导策略探索，并通过与监督策略的 KL 约束减少遗忘。[7, 8]

原因是复杂战术需要一整串协调动作：刚尝试新兵种时，尚未学会配套操作，胜率反而可能下降，训练便会放弃它。人类经验让这些尚未成熟的战术仍有机会被继续探索。[8]

#### 三类智能体分工

联赛同时维护正在训练的智能体和冻结的历史策略；持续对局更新胜率估计，再据此安排对手。[7, Methods: Multi-agent learning]

| 类型                            | 主要训练对象                               | 作用                                         |
| ------------------------------- | ------------------------------------------ | -------------------------------------------- |
| Main agents（主智能体）         | 当前主智能体与联赛历史策略                 | 学习覆盖多种对手的稳健策略，作为最终参赛策略 |
| Main exploiters（主策略利用者） | 当前主智能体，必要时通过历史主策略构造课程 | 专门发现主策略的漏洞，无需对所有对手都强     |
| League exploiters（联赛利用者） | 通过 PFSP 选择联赛历史策略                 | 寻找整个策略池的共同盲点                     |

利用者可以重置回监督学习起点，重新寻找不同的反制；主智能体持续训练。即使某个利用者只擅长一种针对性打法，它也能提供有价值的训练压力。冻结快照则把发现过的反制保留下来。[7, 8]

#### 主智能体怎样分配对局

论文正式联赛中的比例为：[7, Methods: Populating the league]

- **35%**：与当前主智能体自博弈，保持快速学习。
- **50%**：对全部历史策略使用 PFSP。
- **15%**：专门通过 PFSP 应对已经遗忘的历史主策略和过去的主策略利用者；若没有这类需要修补的对手，则改为自博弈。

PFSP 使用 §3 的胜率加权：难对手权重 $(1-w)^p$ 强调弱点；对学习困难的智能体，也可用 $w(1-w)$ 选择势均力敌的对手作为课程。这样，少见却能克制主策略的打法不会被大量容易击败的对手稀释。[7, Methods: Prioritized fictitious self-play]

#### 联赛为什么比单纯历史池更进一步

历史池只能重用已经发现的对手；利用者会主动搜索新的弱点。主策略修补漏洞后，再把新版本加入联赛，形成“发现反制 → 优先训练 → 保存策略”的循环。PFSP 负责分配训练预算，利用者负责拓展反制策略，两者相互配合。[8]

这里的训练安排与 PSRO 有相通之处，但实际对手分布由上述联赛规则产生，不能直接视为每轮精确求解受限博弈纳什均衡。[2, 7]

## 6. 方法对照

| 方法                 | 对手分布如何确定                     | 主要收益                   | 主要代价或边界                                 |
| -------------------- | ------------------------------------ | -------------------------- | ---------------------------------------------- |
| 朴素自博弈           | 只选最新版本                         | 简单、学习推进快           | 非传递循环、遗忘旧对手                         |
| FSP 思路的均匀历史池 | 全历史均匀采样                       | 保留历史覆盖               | 预算可能消耗在容易击败的旧策略上               |
| δ-uniform            | 截取近期历史后均匀采样               | 平衡覆盖与效率             | 截断可能丢失有用反制                           |
| PFSP                 | 根据相对胜率等表现设置优先级         | 集中修补弱点               | 胜率统计与采样函数影响效果                     |
| PSRO                 | 分析受限博弈得到元策略，再学响应扩池 | 显式处理策略间克制与混合解 | 交叉评估、响应训练与元求解成本高；保证依赖条件 |
